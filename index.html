الخصوصية والأمان أولاً

بياناتك وأكوادك في أمان تام.. الخصوصية مبنية في صميم النظام

حرصنا في SCI-BOT ألا يكون مجرد أداة ذكية، بل قلعة أمان تحترم خصوصية الطالب بالكامل:

🔒

عزل تام للمحادثات ومسودات الكود

محادثاتك وأكوادك ومسودات مشاريعك مفصولة ومحمية؛ لا يمكن لطالب آخر رؤيتها ولا تضاف للمعرفة العامة بدون إذنك.

كودك ومحادثاتك ملك لك وحدك
🚫

ممنوع المراقبة أو تقييم الدرجات

لا يمكن استخدام المحادثات كأداة لمراقبة الطلاب أو خصم درجات في المعمل. المنصة مساحة آمنة لتسأل عن أي Bug براحتك.

اسأل عن أي خطأ برمجى دون خوف من التقييم
📊

إحصائيات مجردة فقط للأساتذة (Zero-Exposure)

عضو هيئة التدريس يرى فقط الإحصائيات العامة (مثال: 70% من الطلاب يواجهون صعوبة في شجرة AVL أو الـ Dynamic Programming) ولا يظهر اسم أي طالب نهائياً.

تحسين التدريس دون كشف هوية الطالب
🗑️

حذف حقيقي وشامل للبيانات

عندما تقرر مسح محادثتك، تُحذف فعلياً من قواعد البيانات ومتجهات الـ Vector، وليس مجرد إخفاء شكلي في الواجهة.

True Deletion — لا توجد نسخ غير معلنة
🔐

حماية مفاتيح الـ API والتشفير

مفاتيح الـ API التي تدخلها لا تُحفظ كنصوص مقروءة ولا تظهر في ملفات الـ Logs وتظل تحت إدارتك الآمنة في المتصفح أو مشفرة.

تشفير كامل لمفاتيح الـ API الخاصة بك
🛡️

حماية من حقن الأوامر (Injection Defense)

يتم عزل أي مستند أو سورس كود يتم رفعه وتصنيفه كمدخل غير موثوق به لمنع أي أوامر خبيثة من اختراق سياق النظام والذكاء الاصطناعي.
